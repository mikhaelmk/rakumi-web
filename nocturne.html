NOCTURNE

A quieter orbit for Vencord.

A celestial Vencord theme built around deep navy surfaces, lunar blue and restrained gold.

Download .theme.css

Installation

Online

Settings → Vencord → Themes → Online Themes

Paste the theme URL below and enable Nocturne.

Local

Settings → Vencord → Themes → Local Themes → Open Themes Folder

Download Nocturne.theme.css, place it in the themes folder and enable it.
